# Introduction
A web app that uses NFL play-by-play data and real playbooks to power a network of machine learning models that will predict offensive plays based on any NFL game situation.

# Semester Goals
## Shift to Behavioral Modeling
Re-architect backend models to predict team-specific tendencies rather than theoretically optimal plays.
## Sequential Context Integration
Develop a pipeline to process and interpret consecutive play-calling sequences.
## Analytics-Driven UI
Build a redesigned front-end interface that pairs predicted play visualizations with underlying team statistical tendencies.

# Results and Conclusions
## Team-Specific Predictive Models
Successfully transitioned the backed from a prescriptive (“optimal”) recommendations to predictive, team-specific play-calling forecasts.
## Interactive Multi-Play Interface
Engineered a deeper, more intuitive UI that allows users to visualize and interact with multiple predicted play options simultaneously.
## Contextual Tendency Visualizations
Integrated field-zone performance metrics for various play types, providing transparent, data-backed reasoning behind each model prediction.

# Future Goals
## Full-Field Schematic Context

## Defensive Predictive Modeling
Architect machine learning models to forecast defensive play calls, including personnel groupings, blitz packages, and press alignments.
## Model Refinement
Iterate on current model architectures to improve predictive model accuracy and deepen situational insights.
